# MagicSquare_xx STEP 2 — ECB 설계 프롬프트

## 컨텍스트 (Mom Test 결과)

**주제:** 4×4 부분 마방진(빈칸 2개)을 채울 때 행·열·대각선·1~16 중복 검증을 빠뜨리지 않고, 틀린 해를 늦게 알지 않도록 한다.

**진짜 문제:** 부분 마방진을 채울 때 검증 항목(특히 대각선·1~16 중복)을 빠뜨려 틀린 해를 늦게 알고 같은 실수를 반복하며 시간을 낭비한다.

**성공 기준 (Mom Test 연결):**
1. 대각선 포함 10선 합 34를 모두 검사한다.
2. 1~16 중복·누락 없이 썼는지 확인한다.
3. 같은 검증 실수를 반복하지 않는다.

**표면 문제 (하지 않을 것):** ECB 클래스 이름·UI·도구만 목표로 삼지 않는다.

**이번 세션 8계층:** Rule, Command, (Skill), Test Loop

**실패 조건:**
1. 행·열만 맞고 대각선을 검사하지 않으면 완성으로 오판한다.
2. 1~16 중복·누락 없이 썼는지 확인하지 않으면 잘못된 해를 통과시킨다.
3. 빈칸 위치를 잘못 파악하면 Solver가 엉뚱한 칸을 채운다.

## 작업 요청

4×4 부분 마방진 프로젝트를 ECB 패턴으로 설계·구현해.

### Entity
- `MagicSquare` — 4×4 격자 데이터
- `Cell` — 각 칸의 값, 위치, 상태
- `SolveResult` — 풀이 결과

### Control
- `SquareValidator` — 행·열·대각선 합(34) 및 1~16 중복 검증
- `MissingFinder` — 빈칸 위치 탐색
- `Solver` — 빈칸 2개를 채워 완성

### Boundary
- `GridUI` — 격자 시각화
- `InputHandler` — 사용자 입력
- `ResultDisplay` — 결과 표시
