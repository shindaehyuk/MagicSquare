## MagicSquare_1004 세션 3 워크북

### 1) 주제 한 문장 (Mom Test 기반, 솔루션 최소화)
4×4 부분 마방진(빈칸 2개)을 채울 때 행·열·대각선·1~16 중복 검증을 빠뜨리지 않고, 틀린 해를 늦게 알지 않도록 한다.

### 2) R-G-I-O

| 항목 | 내용 |
|------|------|
| **Role** | 4×4 부분 마방진을 손으로 또는 코드로 다루는 학습자 |
| **Goal** | 빈칸 2개를 채워 10선(행·열·대각) 합 34인 완성 마방진을 만들고, 검증 누락 없이 오답을 빨리 판정한다 |
| **Input** | 4×4 격자 — 빈칸 2개, 나머지 칸에 1~16 중 일부가 채워진 상태 |
| **Output** | 완성된 격자, 또는 어떤 검증(행/열/대각/중복)에서 실패했는지 명확한 판정 |

### 3) 성공 기준 3개 (Mom Test 증거와 연결)

1. **대각선 포함 10선 합 34를 모두 검사한다** — 증거: 「행·열 합은 맞췄는데 대각선 검사를 빼먹어」 늦게 틀림을 알았다.
2. **1~16 중복·누락 없이 썼는지 확인한다** — 증거: 진짜 문제에 「특히 대각선·1~16 중복」 검증 누락이 핵심 불편으로 드러났다.
3. **같은 검증 실수를 반복하지 않는다** — 증거: 「틀렸는지 늦게 알고 시간을 낭비한 적」 + 「같은 실수를 반복」.

### 4) 표면 문제 — 이번 프로젝트에서 하지 않을 것

- 「SquareValidator / MissingFinder / Solver ECB 프로그램을 만든다」에만 매몰하기
- UI·프레임워크·도구 이름(TDD, PyQt, Cursor 등)을 목표로 삼기
- 검증 없이 빈칸만 채우는 Solver 중심 접근

### 8계층 — 이번 세션에서 만드는 것

| 계층 | 이번 세션 |
|------|-----------|
| Rule | ✅ 검증 체크리스트 (행·열·대각·1~16) |
| Command | ✅ 채우기·검증 실행 명령 |
| Skill | (선택) 손계산 또는 간단 검증 스크립트 |
| Test Loop | ✅ 실패 조건별 테스트 3개 이상 |
